# Local MDX Dictionary

本地 MDX 网页词典插件 · Local MDX dictionary extension

正式版 **v1.0.0**。支持多本 MDX 词典和匹配的 MDD 图片、音频资源；点击、划词或可选悬停查词。词典与查询在设备本地处理，不附带词典，不需要账号或 API。

Import your own MDX dictionaries and matching MDD resources. Look up words and selected phrases on webpages. Dictionaries and lookups stay on your device. No dictionaries are bundled.

## 安装 / Install

从 Releases 下载 Chrome ZIP 并解压，在 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”。导入自己的 MDX 文件及匹配的 MDD。

Download and extract the Chrome ZIP from Releases, enable Developer mode in `chrome://extensions`, then choose **Load unpacked**. Import your own MDX and optional matching MDD files.

界面支持简体中文、繁體中文、English、日本語、한국어；语言标题始终同时显示所有语言。
